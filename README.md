
# ExpressionGenCreate

A desktop GUI for batch-generating character expressions and poses via a local [ComfyUI](https://github.com/comfyanonymous/ComfyUI) server. Define a set of expressions (e.g. laugh, cry, angry), each with its own modifier prompt, and generate them all in a single ComfyUI queue pass.

## Features

- Batch-generate multiple expressions from a single shared base prompt
- Full control over model, CLIP, VAE, LoRA stack, sampler, scheduler, CFG, steps, and resolution
- Per-expression prompt modifiers appended to the shared positive prompt (strength-adjustable)
- Save and load named presets
- Optional BiRefNet background removal with configurable model
- Configurable post-generation upscaling (lanczos, bilinear, bicubic, nearest-exact)
- Results gallery showing generated images organized by expression
- Export ComfyUI API-format workflow JSON
- Interrupt running generations from the UI

## Prerequisites

- Python 3.10+
- A running [ComfyUI](https://github.com/comfyanonymous/ComfyUI) instance (default: `http://127.0.0.1:8188`)

### Required ComfyUI custom nodes

This tool builds workflows that depend on two custom node packs:

| Node pack | Nodes used | Purpose |
|---|---|---|
| [rgthree-comfy](https://github.com/rgthree/rgthree-comfy) | `Seed (rgthree)`, `KSampler Config (rgthree)` | Deterministic/incremental seed control and consolidated sampler config |
| A BiRefNetRMBG node pack (e.g. [comfyui-birefnet](https://github.com/1038lab/ComfyUI-BiRefNet)) | `BiRefNetRMBG` | Background removal (optional, controlled via the "Remove background" toggle) |

Install these into your ComfyUI `custom_nodes/` directory before running.

### Model files

The default preset expects these files in your ComfyUI models directories:

| File | ComfyUI directory |
|---|---|
| `Anima_-_base-v1-0.safetensors` | `models/checkpoints/` |
| `qwen_3_06b_base.safetensors` | `models/clip/` |
| `qwen_image_vae.safetensors` | `models/vae/` |
| `BiRefNet_toonout` | `models/birefnet/` (or equivalent) |

The **BiRefNet_toonout** model may not be available in all BiRefNet node packs by default and might need to be downloaded separately. Check the documentation for your installed BiRefNet node pack.

All model names are configurable in the UI, you can substitute any compatible checkpoint, CLIP, VAE, or BiRefNet model.

## Quick start

```
git clone <repo-url>
cd ExpressionGenCreate
py -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py
```

On Windows you can also double-click `run.bat`, which will create the venv and install dependencies automatically on first run.
There should be two presets ready.

## Usage

1. **Start ComfyUI** with your desired models loaded.
2. **Launch ExpressionGenCreate** it opens with a default preset (or your last-used settings).
3. **Configure global settings** in the left panel: checkpoint, CLIP, VAE, LoRAs, resolution, sampler, prompts, output path, and ComfyUI URL.
4. **Add expressions** in the lower-left panel. Each row has a **label** (used for filenames) and a **modifier prompt** (appended to the shared positive prompt as `(modifier:strength)`).
5. **Click Run** to submit the workflow. Generated images appear in the results gallery on the right and are saved to disk.
6. Use **Save** / **Load** to manage named presets, or **Export JSON** to save the raw ComfyUI workflow for use elsewhere.

## Presets

Presets are stored as JSON files in the `presets/` directory. Each preset captures all global settings and the full expression list. The app auto-loads the last-used preset on startup (stored in `presets/__current__.json`).

You can share presets by copying the JSON files, just ensure the target machine has the same (or compatible) model files and custom nodes installed.
